Claude Code 是 Anthropic 推出的命令行 AI 编程助手，可以直接在终端中使用。

安装完成后，在任意项目目录下运行 claude 命令即可开始使用。首次使用需要登录 Anthropic 账号。

直接描述需求，Claude Code 会生成代码并写入文件。描述需求时越具体，结果越准确。
